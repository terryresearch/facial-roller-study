# Source

`/index.html` at the repository root is the deployed study: a single self-contained file,
built by inlining these sources.

Edit the files here, then rebuild:

    python3 build.py

- `config.js`   — endpoints, stimulus copy, magazine names, completion settings
- `measures.js` — the measures, their scales, and the demographics block
- `study.css`   — layout and styling
- `study.js`    — flow, randomisation handling, payload mapping
- `index.html`  — page shell
